# PlayZone---Sistem-Pengelolaan-PlayGround-Anak-Berbasis-Java

PlayZone merupakan aplikasi desktop berbasis Java yang dikembangkan untuk membantu pengelolaan operasional playground (tempat bermain anak). Aplikasi ini dirancang untuk memudahkan admin dalam mengelola transaksi tiket, paket bermain, memantau sesi bermain, serta melihat laporan operasional dalam satu sistem.
